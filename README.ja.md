# Live2D風エフェクト拡張機能 for TurboWarp

TurboWarp用の拡張機能で、メッシュベースの変形と四角形マッピングを使用したLive2D風の画像変形・変形エフェクトを提供します。

> 📚 **ドキュメント**: [クイックスタート](QUICKSTART.ja.md) | [使用例](EXAMPLES.ja.md) | [貢献](CONTRIBUTING.ja.md) | [アーキテクチャ](ARCHITECTURE.ja.md) | [English](README.md)

## 機能

### 🎨 画像変形機能

- **四角形メッシュ変形**: 4つの頂点を制御して、長方形の画像を任意の四角形に変形
- **プリセット変形**: 台形、遠近法、波、膨張などの一般的なエフェクトを素早く適用
- **柔軟な画像読み込み**: Scratchコスチュームまたは外部URLから画像を読み込み
- **精密な頂点制御**: 各頂点のX・Y座標を個別に設定
- **スムーズな補間**: バイリニア補間とメッシュ分割による滑らかな変形

### 📦 ブロックカテゴリ

#### 画像の読み込み
- `コスチューム [costume] から画像を読み込む` - Scratchコスチュームから画像を読み込み
- `URL [url] から画像を読み込む` - 外部URLから画像を読み込み

#### 頂点制御
- `頂点 [vertex] を x: [x] y: [y] に設定` - 個別の頂点位置を設定
- `頂点 [vertex] の x` - 頂点のX座標を取得
- `頂点 [vertex] の y` - 頂点のY座標を取得

頂点:
- 左上 (Top Left)
- 右上 (Top Right)
- 左下 (Bottom Left)
- 右下 (Bottom Right)

#### 変形プリセット
- `[preset] 変形を適用 強さ: [strength]%` - プリセット変形を適用

利用可能なプリセット:
- **台形 (Trapezoid)**: 上辺を狭めて台形形状を作成
- **遠近法 (Perspective)**: 3D遠近感のエフェクトを作成
- **波 (Wave)**: 正弦波による歪み効果を適用
- **膨張 (Bulge)**: 中心から外側に膨らむ効果

#### 描画
- `変形した画像を x: [x] y: [y] に描画` - 指定座標に変形画像を描画
- `変形した画像を x: [x] y: [y] 幅: [width] 高さ: [height] に描画` - カスタムサイズで描画

#### ユーティリティ
- `すべての変形をリセット` - すべての頂点を元の位置にリセット
- `画像の幅` - 読み込まれた画像の幅を取得
- `画像の高さ` - 読み込まれた画像の高さを取得

## 使用例

### 基本的な台形エフェクト

```scratch
緑の旗がクリックされたとき
コスチューム [character-1] から画像を読み込む
[台形] 変形を適用 強さ: (50)%
変形した画像を x: (0) y: (0) に描画
```

### カスタム頂点アニメーション

```scratch
緑の旗がクリックされたとき
コスチューム [character-1] から画像を読み込む
ずっと
  頂点 [右上] を x: (100) y: ((-20) から (20) までの乱数) に設定
  頂点 [右下] を x: (100) y: (100 + ((-20) から (20) までの乱数)) に設定
  変形した画像を x: (0) y: (0) に描画
  (0.1) 秒待つ
end
```

### 旗がはためくエフェクト

```scratch
緑の旗がクリックされたとき
コスチューム [flag] から画像を読み込む
ずっと
  [time v] を (0.1) ずつ変える
  頂点 [右上] を x: (100) y: ((time の sin) × (10)) に設定
  頂点 [右下] を x: (100) y: (100 + ((time + 90) の sin) × (10)) に設定
  変形した画像を x: (0) y: (0) に描画
end
```

### 遠近法変形

```scratch
緑の旗がクリックされたとき
コスチューム [background] から画像を読み込む
[遠近法] 変形を適用 強さ: (75)%
変形した画像を x: (0) y: (0) 幅: (480) 高さ: (360) に描画
```

## 技術的詳細

### 座標系

拡張機能は内部的に正規化された座標系（0-1）を頂点位置に使用し、レンダリング時に実際の画像サイズにスケールします。

- `(0, 0)` = 左上隅
- `(1, 0)` = 右上隅
- `(0, 1)` = 左下隅
- `(1, 1)` = 右下隅

ただし、頂点位置を設定する際は、負の値や画像サイズより大きい値など、任意の座標値を使用できます。

### メッシュ変形アルゴリズム

拡張機能は画像を10×10のグリッドに分割し、各セルにバイリニア補間を適用します。これにより、良好なパフォーマンスを維持しながら滑らかな変形を実現します。

変形プロセス:
1. 画像をメッシュグリッドに分割
2. 各グリッドセルを個別に変形
3. バイリニア補間で中間位置を計算
4. Canvas 2D変形APIで変形を適用
5. 結果をステージに合成

### パフォーマンスに関する考慮事項

- **メッシュ分割**: デフォルトで10×10メッシュグリッドを使用し、品質とパフォーマンスのバランスを取っています
- **画像サイズ**: 大きな画像は変形に時間がかかる場合があります
- **頻繁な更新**: アニメーション用には、パフォーマンスに問題がある場合、更新頻度を下げることを検討してください

## インストール

### 方法1: URLから読み込み（開発時推奨）

1. TurboWarpを開く
2. 左下の拡張機能アイコン（フォルダアイコン）をクリック
3. 「カスタム拡張機能」を選択
4. `live2d-effect.js`へのURLを入力
5. 「読み込む」をクリック

### 方法2: ローカル開発

1. このリポジトリをクローン
2. ローカルWebサーバーで拡張機能ファイルを提供
3. TurboWarpで`http://localhost:ポート/extensions/live2d-effect.js`をカスタム拡張機能として読み込む

## ブラウザ互換性

この拡張機能には以下が必要です:
- Canvas 2D APIサポート
- ES6+のJavaScript機能
- 外部画像読み込み用のクロスオリジンリソース共有（CORS）サポート

動作確認済み:
- Chrome/Chromium 90+
- Firefox 88+
- Safari 14+
- TurboWarp Desktop

## 制限事項

- 拡張機能が正常に機能するには、サンドボックス化されていないモードが必要です
- 外部画像は適切なCORSヘッダーで提供される必要があります
- 非常に大きな画像はパフォーマンスに影響を与える可能性があります
- 変形は2Dのみです（真の3D回転はありません）

## 高度な使用法

### カスタムプリセットの作成

拡張機能には組み込みプリセットが用意されていますが、4つの頂点をすべて手動で設定することでカスタムエフェクトを作成できます:

```scratch
緑の旗がクリックされたとき
コスチューム [sprite] から画像を読み込む
// ダイヤモンド形状を作成
頂点 [左上] を x: (50) y: (0) に設定
頂点 [右上] を x: (100) y: (50) に設定
頂点 [右下] を x: (50) y: (100) に設定
頂点 [左下] を x: (0) y: (50) に設定
変形した画像を x: (0) y: (0) に描画
```

## トラブルシューティング

### 画像が読み込まれない
- コスチューム名が正しいことを確認（大文字小文字を区別）
- URLの場合、CORSヘッダーが適切に設定されているか確認
- 画像形式がサポートされているか確認（PNG、JPEG）

### 変形が表示されない
- 最初に画像を読み込んだことを確認
- 頂点位置が有効な四角形を作成していることを確認
- 頂点設定後に描画コマンドが呼び出されているか確認

### パフォーマンスの問題
- 画像サイズを小さくする
- 更新頻度を下げる
- よりシンプルな変形を使用する
