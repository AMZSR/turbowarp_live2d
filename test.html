Loading in TurboWarp

  1. Open TurboWarp (https://turbowarp.org/)
  2. Click on the Extensions icon (puzzle piece) in the bottom-left
  3. Select "Custom Extension"
  4. Enter the URL to your hosted extension file
  5. Click "Load"

Technical Implementation

The extension uses the following techniques:

  • Canvas 2D API: For image rendering and transformation
  • Mesh Subdivision: Divides the image into a 10x10 grid
  • Bilinear Interpolation: Smoothly interpolates vertex positions across the mesh
  • Affine Transforms: Applied to each mesh cell for accurate deformation
  • Normalized Coordinates: Internal 0-1 coordinate system for flexibility
