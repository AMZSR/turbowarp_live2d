# Example Projects

This directory contains example projects demonstrating the Live2D Effect extension.

## Available Examples

Currently, examples are provided as code blocks in the [EXAMPLES.md](../EXAMPLES.md) file. You can copy these block scripts directly into TurboWarp.

## Creating Your Own Examples

To create and share example projects:

1. Build your project in TurboWarp
2. Use the Live2D Effect blocks
3. Export as `.sb3` file
4. (Optional) Contribute back to this repository

## Quick Examples Overview

### Beginner Examples
- **Simple Trapezoid** - Basic preset transformation
- **Basic Wave** - Animated wave effect
- **Interactive Perspective** - Mouse-controlled transformation

### Intermediate Examples
- **Waving Flag** - Complex animated effect
- **Character Head Tilt** - Custom vertex animation
- **Screen Shake** - Impact effect using random vertices

### Advanced Examples
- **Smooth Transitions** - Interpolated animations
- **Custom Shapes** - Manual vertex positioning
- **Layered Effects** - Combining multiple transformations

## How to Use Examples

1. Load the Live2D Effect extension in TurboWarp
2. Copy the code blocks from EXAMPLES.md
3. Recreate the blocks in your TurboWarp project
4. Modify and experiment!

## Contributing Examples

If you create an interesting project using the Live2D Effect extension:

1. Document your blocks clearly
2. Include a description of what it does
3. Add screenshots if possible
4. Submit a pull request to add it to EXAMPLES.md

See [CONTRIBUTING.md](../CONTRIBUTING.md) for more details on contributing.
